Profile lookup

Use your LinkedIn cookies from this browser session (both values together). Then paste a profile URL.

  1. Open Chrome and sign in at https://www.linkedin.com (your own account).
  2. Open DevTools: Mac Cmd + Option + I · Windows/Linux F12 or Ctrl + Shift + I.
  3. Click the Application tab (if you do not see it, click >>).
  4. Left sidebar: Storage → Cookies → https://www.linkedin.com (or .www.linkedin.com).
  5. In the cookie list find the name li_at. Copy the Value column only.
  1. Stay in the same DevTools Cookies table as for li_at (same site, same moment).
  2. Find the cookie named JSESSIONID.
  3. Copy the Value. It looks like ajax:7140…. Surrounding quotes are optional.
  4. Do not mix this with an li_at from another browser, profile, or an older copy. CSRF is tied to this pair.
